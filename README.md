# Piper Desktop Releases
* v0.2.0: First public release of the Piper Desktop App
* v0.2.1: Add support for Microsoft login
* v0.2.2: Add audio note recording for past meetings and tabbed navigation in the app
* v0.2.3: Add audio note recording without a meeting, start recording from notifications, and launch Piper Desktop at login
* v0.2.4: Add lead support, block CRM access for read-only users, and check permissions before recording
* v0.2.5: Add Auto-Capture, meeting start notifications, local recording with bot in call, computer audio in voice notes, support for more meeting providers, and recording confirmation for transcripts
* v0.2.6: Add local backup for recorded audio and WhatsApp support, and fix call duration and huddle detection
* v0.2.7: Recording session screen, refresh activities button, rename activity titles, option to discard recordings, and longer Auto-Capture window
* v0.2.8: Add app menu bar for quick access, sync theme across windows, and fix recording end timer
* v0.2.9: Fix menu bar popover bug
* v0.2.10: Fix menu bar images and dock icon on macOS, and show error page when recording fails
* v1.0.0: Official 1.0 release with beta update channel
* v1.0.1: Fix audio note upload with automatic retry before showing errors
* v1.1.0: Add always record locally button, Auto-Record provider selection, meeting timer on menu bar, automatic sign-out on session expiry, and fix call duration during calendar meetings
* v1.2.0: Maintenance release
